# IT Support — Система обліку заявок на ремонт комп'ютерної техніки

## 1. Опис проєкту

**IT Support** — це вебзастосунок для створення, обліку та опрацювання заявок на ремонт комп'ютерної техніки.

Система дозволяє користувачам створювати заявки, переглядати їхній стан та отримувати інформацію про результати ремонту. Адміністратори й менеджери можуть переглядати заявки та контролювати процес їх виконання.

## 2. Основні можливості

### Користувач (user)
- Реєстрація та авторизація.
- Створення заявок на ремонт.
- Перегляд власних заявок.
- Пошук заявок за назвою.
- Фільтрація заявок за статусом.
- Перегляд статусів і коментарів адміністратора.
- Редагування контактних даних профілю.

### Адміністратор (admin)
- Перегляд усіх заявок.
- Пошук і фільтрація заявок.
- Зміна статусів і пріоритетів.
- Додавання коментарів адміністратора.
- Додавання інформації про результати ремонту.
- Перегляд заявок і керування їх опрацюванням.

### Менеджер (manager)
- Перегляд усіх заявок.
- Пошук і фільтрація заявок.
- Контроль статусів і пріоритетів.
- Перегляд статистики заявок.

## 3. Використані технології

- **HTML5** — структура вебсторінок.
- **CSS3** — оформлення та стилізація інтерфейсу.
- **JavaScript** — логіка застосунку та взаємодія з базою даних.
- **Supabase Auth** — реєстрація, авторизація та керування сеансами.
- **PostgreSQL** — зберігання даних.
- **Row Level Security (RLS)** — розмежування доступу до даних залежно від ролі користувача.

## 5. Налаштування Supabase

Для роботи застосунку необхідно створити проєкт у Supabase.

У базі даних використовуються дві основні таблиці:

**profiles** — зберігає інформацію про користувачів:
- id
- full_name
- email
- role
- phone
- created_at

**repair_requests** — зберігає інформацію про заявки:
- id
- user_id
- title
- equipment_type
- inventory_number
- location
- description
- status
- priority
- admin_comment
- resolution
- created_at
- updated_at

Для таблиць налаштовано Row Level Security (RLS), який обмежує доступ до даних відповідно до ролей користувачів.

## 6. Підключення до Supabase

Для підключення застосунку використовується файл `js/supabase.js`.

У ньому необхідно вказати URL свого проєкту Supabase та публічний ключ (Publishable key або legacy anon key).

**Важливо:** не можна використовувати або публікувати секретний ключ `service_role` у клієнтському коді.

## 7. Запуск проєкту

1. Завантажити або скопіювати файли проєкту.
2. Створити та налаштувати проєкт у Supabase.
3. Перевірити правильність URL і публічного ключа у `js/supabase.js`.
4. Відкрити папку проєкту у Visual Studio Code.
5. Запустити `index.html` через Live Server.
6. Зареєструвати користувача або увійти в наявний обліковий запис.

## 8. Ролі користувачів

У системі передбачено три ролі:

| Роль | Призначення |
|---|---|
| user | Створення та перегляд власних заявок |
| manager | Контроль заявок і перегляд статистики |
| admin | Повне опрацювання заявок |

Новим користувачам автоматично призначається роль `user`. Ролі `admin` та `manager` призначаються довіреним адміністративним механізмом.

## 9. Статуси та пріоритети заявок

**Статуси:**
- `new` — нова заявка.
- `in_progress` — заявка в роботі.
- `waiting` — очікування.
- `completed` — ремонт завершено.
- `rejected` — заявку відхилено.

**Пріоритети:**
- `low` — низький.
- `medium` — середній.
- `high` — високий.
- `critical` — критичний.
